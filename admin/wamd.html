WAMD verification workflow

WAMD payments remain pending until an authorized administrator reviews the submitted transaction information and approves or rejects the submission.

1
Customer pays Customer completes the WAMD payment.
2
Reference submitted Transaction code is submitted against the payment.
3
Admin reviews Administrator checks reference, amount and order.
4
Payment finalized Approved payments proceed through the secure finalization flow.

Protection layer

Financial verification is not trusted to the browser.

✓
Admin authorization The secure RPC verifies administrator access.
↔
Payment binding WAMD submission remains linked to its payment and order.
#
Transaction reference Transaction codes are protected from duplicate reuse.
▤
Audit trail Verification decisions are recorded in the audit system.
