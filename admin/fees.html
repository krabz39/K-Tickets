Financial configuration is protected

Fee values affect customer charges and merchant earnings. The browser never receives service-role credentials and cannot directly change fee settings. Production updates must go through an authorized, atomic server-side RPC or Edge Function with validation and audit logging.

Secure mutation required

Fee changes must not be performed with a normal browser insert, update or delete. The production implementation should use a server-side function such as an authorized fee-management RPC that validates the new value, applies bounds, prevents conflicting active configurations, records the administrator identity and writes an audit event.
