WAMD verification workflow

A manual WAMD payment remains pending until an authorized administrator verifies the submitted transaction reference and confirms the payment against the related order.

1
Customer pays Customer completes the WAMD payment outside K-Tickets.
2
Reference submitted Transaction reference is attached to the order.
3
Admin reviews Admin validates the submitted information.
4
Order confirmed Only successful verification may unlock ticket fulfilment.

Protection layer

Verification actions must never rely on the browser alone.

✓
Admin authorization Server verifies the authenticated admin role.
↔
Order binding Verification must be tied to the correct order.
#
Reference uniqueness Reuse of a transaction reference should be rejected.
▤
Audit logging Every verification decision should be recorded.
