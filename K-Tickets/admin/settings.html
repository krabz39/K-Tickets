Account deletion / role changes

Do not perform privileged account deletion, role elevation, ownership transfer or similar actions directly from client-side JavaScript. These operations require a protected backend workflow with explicit authorization and audit logging.

✓
K-Tickets settings are secure-by-design

The browser uses only the Supabase anon key and the authenticated administrator session. Sensitive credentials are never exposed here. Production deployments should enforce all important settings through PostgreSQL RLS, protected RPCs or Edge Functions, with audit logging for privileged changes.
